## 5.5 Run in Android Studio (Recommended)

### A) Open project correctly

1. Open Android Studio.
2. Click `Open`.
3. Select: `F:\Final Year Project\frontend` (open Flutter project root, not only `android/`).
4. Wait for Gradle + Flutter indexing to finish.

### B) Check SDK settings once

1. Android Studio -> `Settings` -> `Languages & Frameworks` -> `Flutter`.
2. Set Flutter SDK path.
3. `Settings` -> `Android SDK`:
- Install one SDK platform (for example API 34).
- Install SDK Platform-Tools.
- Install Android Emulator.

### C) Start emulator / connect device

1. Open `Device Manager`.
2. Start an AVD emulator.
3. Or connect physical Android device with USB debugging enabled.

### D) Run backend first (required)

Open terminal and run:

```powershell

backend\venv\Scripts\python.exe -m uvicorn backend.main:app --reload
```

### E) Set API base URL in Android Studio Run Configuration

1. Top bar -> Run configuration dropdown -> `Edit Configurations...`
2. Select your Flutter run config.
3. In `Additional run args`, set:

```text
--dart-define=API_BASE_URL=http://10.0.2.2:8000
```

Use this value for Android emulator.  
If using real phone on same Wi-Fi, use your PC LAN IP:

```text
--dart-define=API_BASE_URL=http://<YOUR_PC_LAN_IP>:8000
```

### F) Run app

1. Select emulator/device from top toolbar.
2. Click `Run` (green play button).
3. Check logs in `Run` tab for API/auth errors.

### G) If app cannot connect backend

1. Confirm backend is running on port `8000`.
2. Open `http://127.0.0.1:8000/health` on your PC browser.
3. Emulator must use `10.0.2.2`, not `127.0.0.1`.
4. Windows Firewall may need to allow Python/Uvicorn for private network.

## 7) Required APIs and Exact Env Keys

Edit `F:\Final Year Project\backend\.env`.

Required:

```env
OPENAI_API_KEY=your_openai_key
OPENAI_MODEL=gpt-4o-mini
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
WHISPER_MODEL=whisper-1
DB_PATH=travel_buddy.db
FIREBASE_CREDENTIALS_PATH=backend/firebase_service_account.json
AUTH_BYPASS=false
```

Note: relative `DB_PATH` values are resolved from the `backend/` directory.
So `DB_PATH=travel_buddy.db` always targets `backend/travel_buddy.db`, whether
you run the backend from the project root or from `backend/`.

Optional but recommended:

```env
DEEPGRAM_API_KEY=your_deepgram_key
OPENWEATHERMAP_API_KEY=your_openweather_key
GOOGLE_MAPS_API_KEY=your_google_maps_key
NEWS_API_KEY=your_newsapi_key
OPENAI_MODEL_FALLBACKS=gpt-4o-mini,gpt-4.1-mini,gpt-3.5-turbo
OPENAI_MAX_RETRIES=3
RAG_SIMILARITY_THRESHOLD=0.30
```

Where these are used:
- `OPENAI_API_KEY`: chat, intent logic, diary AI, STT path fallback.
- `WHISPER_MODEL`: voice transcription.
- `OPENAI_EMBEDDING_MODEL`: RAG memory embeddings.
- `GOOGLE_MAPS_API_KEY`: traffic alerts with origin/destination.
- `OPENWEATHERMAP_API_KEY`: weather alerts.
- `NEWS_API_KEY`: news alerts.
- `FIREBASE_CREDENTIALS_PATH`: backend token verification.
