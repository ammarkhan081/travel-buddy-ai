# FYP Mobile App

A cross-platform Flutter application (Final Year Project) integrating Firebase services and native Android components. The project combines Dart (Flutter) for UI and business logic with native Kotlin/Java modules where required. It targets Android, iOS, Web, Windows, macOS, and Linux.

## Key Features
- Firebase authentication, Firestore, and Storage integration
- Google Sign-In and email/password auth
- Media capture and uploads (image/audio/video)
- Platform-specific native integrations (Android Kotlin/Java modules)
- Responsive UI and theming

## Tech Stack
- Flutter / Dart
- Android (Kotlin, Java, Gradle)
- iOS (Swift/Obj-C bridge via Flutter)
- Desktop (Windows, macOS, Linux C++/CMake)
- Firebase (Auth, Firestore, Storage)
- Common build tools: `gradle`, `pub`

## Repository Structure (top-level)
- `lib/` — Dart source, contains `main.dart`, `firebase_options.dart`, `screens/`, `services/`, `widgets/`, `theme/`
- `android/` — Android native project, Gradle/Kotlin files, `app/google-services.json`
- `ios/`, `macos/`, `linux/`, `windows/`, `web/` — platform folders
- `build/` — build artifacts
- `test/` — unit/widget tests
- `pubspec.yaml` — Dart dependencies
- `firebase.json` — Firebase hosting / emulator config

## Prerequisites
- Flutter SDK (stable) installed and on `PATH`
- Android Studio (Android SDK, emulator or device)
- Xcode for iOS builds (macOS only)
- Node.js and Firebase CLI (if using hosting/emulators)
- Valid Firebase project and credentials

## Setup & Installation
1. Clone the repository and enter project folder:
   - git clone <repo-url>
   - cd `fyp`
2. Install Dart/Flutter packages:
   - flutter pub get
3. Configure Firebase:
   - Place Android `google-services.json` into `android/app/`
   - For iOS, add the appropriate `GoogleService-Info.plist` to `ios/Runner/`
   - Ensure `lib/firebase_options.dart` matches your Firebase project (generated by `flutterfire` CLI)
4. (Optional) Set local properties:
   - Update `android/local.properties` with SDK paths if needed

## Running the App
- Android:
  - flutter run -d <device-id> (or use Android Studio)
- iOS:
  - flutter run -d <device-id> (macOS + Xcode required)
- Web:
  - flutter run -d chrome
- Desktop:
  - flutter run -d windows|macos|linux

## Troubleshooting
- Gradle or Android build errors: run `./gradlew clean` in `android/`, check `local.properties` for SDK path.
- Firebase runtime issues: confirm `lib/firebase_options.dart` and platform config files match the Firebase project.
- Missing native plugin builds: run `flutter pub get` then `flutter build` for the target platform.
